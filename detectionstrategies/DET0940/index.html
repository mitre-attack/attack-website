Detection of Mobile Application Delivery Outside Authorized Distribution Channels

Technique Detected:  Deliver Malicious Application via Other Means | T1476

ID: DET0940
Domains: Mobile
Analytics: AN2290, AN2291
Version: 1.0
Created: 02 November 2026
Last Modified: 03 November 2026
Version Permalink
Live Version

Analytics

  • Android
  • iOS

AN2290

On managed Android devices with the necessary network and security telemetry enabled, identify an application package retrieved through a browser, messaging application, third-party store, or another external delivery mechanism. Correlate the package retrieval with a subsequent installation event on the same device, using package identity, delivery source, timing, and installer provenance where available.

Prioritize cases where the delivery source is outside approved distribution channels, the installer is inconsistent with authorized workflows, and the application is not approved for the device or user. Exclude sanctioned enterprise deployments, approved testing, and documented alternative distribution channels.

AN2291

On managed iOS devices, identify observable delivery of an application package or distribution link through an external website, messaging channel, or other non-approved distribution mechanism.

Where managed network inspection exposes the transaction, identify application-package retrieval or a distribution workflow outside the organization's approved channels. Correlate this with an application newly appearing in device inventory or with a managed-app lifecycle change, using bundle identifier, distribution attributes, and timing where available.

Prioritize cases where the distribution evidence is independently observed and inconsistent with authorized enterprise distribution, alternative marketplaces, or approved testing workflows.
