Kali365

Kali365 is a Phishing-as-a-Service (PHaaS) kit first observed in April 2026 that generates victim-targeted lures across multiple operating systems to induce users into copying and pasting actor-controlled commands for local execution.[1][2][3][4] Kali365 incorporates on-demand device code generation and mirrors the copy-paste execution tradecraft associated with ClickFix. [3] Operators have used Kali365 to harvest victims' OAuth tokens and session cookies through adversary-in-the-middle (AiTM) interception, enabling account takeover.[1][5][2][3][4] Kali365 PHaaS was first observed in April 2026.[1] Kali365 has also been affiliated with other branding to include Octopi365 and Freedom365.[3]

Techniques Used

Domain ID Name Use
Enterprise T1087 .003 Account Discovery: Email Account

Kali365 has leveraged an Exchange Admin module that utilizes Graph to enumerate mailboxes in victim environments.[3]
Enterprise T1557 Adversary-in-the-Middle

Kali365 has created obfuscated phishing landing pages that act as an adversary in the middle infrastructure that intercepts communications between the victim host and legitimate services to steal credentials and user sessions.[1][5][4]
Enterprise T1071 .001 Application Layer Protocol: Web Protocols

Kali365's desktop client has made Microsoft Graph API calls using the distinct User-Agent string kali365-live/1.0.0 to access victim mailboxes and enumerate account data following OAuth token capture.[1]
Enterprise T1185 Browser Session Hijacking

Kali365 has gathered browser session information and allows affiliate threat actors to replay stolen browser sessions within their own environment.[1]
Enterprise T1059 .007 Command and Scripting Interpreter: JavaScript

Kali365 has executed JavaScript within victims' browsers through a React frontend that detects browser sessions to evade automated analysis, auto-copies actor-generated device codes to the victim's clipboard, and polls the actor's C2 infrastructure every three seconds to confirm when OAuth token capture has completed..[1][5][3]
Enterprise T1683 .001 Generate Content: Written Content

Kali365 has generated tailored branded phishing lures to target victims utilizing a myriad of reputable services and brands that entice users to interact with the content.[1][5][2][3] Kali365 has also been enabled with AI such as Claude Sonnet that evaluates emails and generates tailored responses to facilitate BEC activities.[3]
Enterprise T1564 .008 Hide Artifacts: Email Hiding Rules

Kali365 has the ability to modify email rules to delete email based notifications prior to the victim seeing them.[4]
Enterprise T1566 .001 Phishing: Spearphishing Attachment

Kali365 has delivered phishing emails with malicious PDF, Word, Excel, and PowerPoint attachments that direct victims to actor-controlled landing pages. [1]
.002 Phishing: Spearphishing Link

Kali365 has sent bulk phishing emails containing malicious hyperlinks that direct victims to actor-controlled landing pages impersonating services including SharePoint, OneDrive, Teams, DocuSign, and Adobe Acrobat Sign. [1]
Enterprise T1090 Proxy

Kali365 has leveraged Cloudflare workers as reverse proxy infrastructure.[1][3][4]
Enterprise T1528 Steal Application Access Token

Kali365 has obtained OAuth access and refresh tokens by deceiving victims into completing actor-initiated device authorization requests, and intercepting authentication sessions with legitimate identity providers through adversary-in-the-middle reverse proxy infrastructure. [1][5][2][4]
Enterprise T1539 Steal Web Session Cookie

Kali365 has captured session cookies and related session artifacts when the interacted phishing lure acts as proxy for legitimate requests with login services.[1][4]
Enterprise T1552 .001 Unsecured Credentials: Credentials In Files

Kali365 has searched compromised mailboxes for credential material such as seed phrases and API keys.[3]
Enterprise T1550 .001 Use Alternate Authentication Material: Application Access Token

Kali365 has utilized an Exchange Admin module that captured admin tokens to create rogue mailbox connectors and change mail-flow rules.[3]
Enterprise T1204 .001 User Execution: Malicious Link

Kali365 has directed victims to actor-controlled phishing pages through malicious links, initiating device code authorization flows or adversary-in-the-middle session capture. [1][3]
.004 User Execution: Malicious Copy and Paste

Kali365 has dynamically generated legitimate device codes that displays on the victims screen alongside instructions to copy and paste the device code to initiate and complete a successful authentication process.[1][5][2][3][4]
Enterprise T1102 Web Service

Kali365 has used Cloudflare Workers to redirect traffic and to host malicious phishing pages.[1][5][4] Kali365 has also leveraged Telegram chat to facilitate administrative tasks for the panel across affiliate users.[1][2][4]
